En la pestaña Catálogos administras las listas de valores maestros compartidas entre todos los tenants de la plataforma. Estos catálogos definen datos estructurados como países, categorías de respuestas, tipos de archivos permitidos y otras clasificaciones del sistema que se utilizan en múltiples módulos.

<Note>
  Desde esta interfaz se editan los valores específicos, campos asociados y patrones de validación (regex), mientras que la estructura base de cada catálogo es definida mediante código por el equipo técnico.
</Note>

## Filtros por módulo

- **Módulo**: menú desplegable para listar y seleccionar un catálogo específico por su nombre de módulo (por ejemplo, `settings` o `canned-responses`), o visualizar todos simultáneamente.

## Tabla de catálogos maestros

| Columna | Descripción |
| --- | --- |
| **Módulo** | Nombre identificador del módulo al que pertenece el catálogo. |
| **Clave** | Identificador único y técnico del catálogo dentro de su módulo. |
| **Descripción** | Texto explicativo que detalla el propósito de la lista de valores. |
| **# Ítems** | Cantidad de valores individuales registrados dentro del catálogo. |
| **Acciones** | Botón **Editar** para acceder a la gestión detallada de los ítems y configuraciones del catálogo. |

<Tip>
  Usa el filtro de **Módulo** para encontrar rápidamente el catálogo que necesitas editar cuando la lista es extensa. Escribe el nombre del módulo (como `settings`) para filtrar al instante.
</Tip>
