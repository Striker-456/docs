SoulChat WP es el módulo de mensajería de la plataforma SOUL. Al ingresar, accedes a un entorno centralizado para gestionar conversaciones, flujos, ajustes y monitoreo del sistema.

## Pantalla de bienvenida

Al abrir SoulChat WP se muestra la pantalla de bienvenida con acceso a todas las funcionalidades del módulo.

![Pantalla de bienvenida SOUL](/images/soulchat/bienvenida.png)

La pantalla muestra el mensaje principal **"¡Bienvenido a Soul!"** con el subtítulo "Gestiona tus aplicaciones, roles y usuarios de manera centralizada." y el botón **Explorar** para comenzar a navegar.

## Menú lateral

El menú lateral izquierdo contiene el acceso directo a cada módulo de SoulChat WP.

| Sección | Descripción |
| --- | --- |
| Chat | Gestión de conversaciones activas |
| Ajustes | Configuración del canal y comportamiento |
| Sistema | Logs, auditoría y monitoreo técnico |
| Flow Builder | Diseño y publicación de flujos conversacionales |
| AI Agent | Configuración de agentes de IA |
| Dashboard | Métricas y estadísticas en tiempo real |

## Tu perfil de agente

Identifica tu información de sesión en dos ubicaciones clave de la interfaz:

| Ubicación | Elemento visible |
| --- | --- |
| Esquina inferior izquierda | Nombre del usuario (ej: **Soul**) con indicador de sesión activa |
| Esquina superior derecha | Nombre completo (ej: **Hector Velásquez**) con opciones de perfil |

## Cerrar sesión

Para finalizar tu sesión de forma segura, sigue estos pasos:

<Steps>
  <Step title="Ubica el botón Cerrar sesión">
    Busca el elemento **Cerrar sesión** en la parte inferior del menú lateral izquierdo.
  </Step>
  <Step title="Haz clic para salir">
    Haz clic para finalizar tu sesión y regresar a la pantalla de autenticación.
  </Step>
</Steps>

<Tip>
  Después de ingresar, ve directamente al módulo **Chat** para revisar tus conversaciones activas o al **Dashboard** para ver las métricas en tiempo real.
</Tip>
